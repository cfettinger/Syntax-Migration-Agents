IMPORTANT NOTES:
─────────────────────────────────────────────────────────────────────────────

Resume Logic & Idempotency:
  - Job claiming is atomic (conditional DB update)
  - RowsWritten tracking prevents duplicate inserts on retry
  - Delstat truncation only on first run (RowsWritten == 0)
  - Can safely re-run same ImportJob if Function crashes mid-process

Architecture Decision:
  - NOT porting WinForms UI (removed entirely)
  - NOT keeping legacy VB.NET code in production
  - Migrating to Azure serverless pipeline (API + Function + Storage + SQL)
  - Website (ASP.NET 3.5) follows later via separate websitespec.md project

Fixed-Width Record Format:
  - 309 bytes per record, ASCII encoding
  - Supports both raw LF and CRLF line endings (sniff on read)
  - D records only (skip C records for header/trailer)
  - 0-based offsets: ZipCode at index 1, RouteID at index 36, etc.
  - Fail-fast on malformed: no silent skipping

Queue Visibility & Renewal:
  - Visibility timeout: 5 minutes (configurable)
  - Periodically update message visibility during processing
  - Ensures Function can handle imports longer than 5 minutes
  - Prevents premature queue re-delivery
